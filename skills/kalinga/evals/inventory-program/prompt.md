Write me a Kalinga program, inventory.kl. It should have an Item class (name, price as a float, quantity) and an Inventory class that can add an item, remove an item by name, give the total value of everything in stock, and find the most expensive item (there might not be one if the inventory is empty). In main, add a few items, remove one, and print the total and the most expensive item's name.
